# EpicGames-RoboCopy
Il programma consente di spostare i file di installazione da un disco ad un altro su EpicGames come su Steam

Descrizione del progetto

In una notte di Maggio, mentre riordinavo il mio sistema, mi sono reso conto di un fatto imperdonabile:
Epic Games non consente (come invece fa Steam) di spostare la cartella di installazione da un disco all'altro.
Praticamente, se hai la memoria un po’ piena, tocca disinstallare e reinstallare tutto. E il messaggio che ti arriva è un bel "Ci pensavi prima".
Nonostante il mio livello di frustrazione, ho deciso di non farmi prendere dal panico. Invece di fare CTRL+C CTRL+D come qualsiasi persona normale farebbe, ho pensato: "Vabbè, me la faccio da solo!". Ed è così che è nato questo programma.

Lo script ti chiederà le informazioni necessarie (nome del gioco, percorso di installazione attuale, destinazione del trasferimento) e si occuperà di tutto il resto: copia o spostamento dei file senza farti impazzire.
Non dovrai riavviare Epic Games Launcher per far riconoscere i file spostati, ma devi solo selezionare la nuova destinazione durante l’installazione nel launcher.

**ATTENZIONE/ISTRUZIONI**:

1. Chiudi Epic Games Launcher prima di avviare il programma, per evitare conflitti tra i file in uso.
2. Avvia il programma come Amministratore. Dopo lo spostamento, Epic Games Launcher si aprirà automaticamente.
3. Inserisci i dati richiesti dal programma con precisione.
4. Prenditi un caffè (o due) mentre il programma lavora. (Essenziale).
5. Dopo lo spostamento, reinstalla il gioco, selezionando, quando Epic te lo chiede, una cartella DIVERSA da quella di origine che avevi selezionato sul mio programma.
6. Premi “Installa” e Epic Games Launcher farà una scansione alla ricerca dei file che hai spostato. (Spoiler: Li troverà).
7. Bonus: Guarda la velocità della barra di download schizzare come una scheggia!
8. Gioca!

Nota: Se sposti giochi pesanti come HITMAN III, il processo potrebbe richiedere più di un caffè.

**In caso di problemi**:
Vai in `C:\ProgramData\Epic\UnrealEngineLauncher` e apri il file LauncherInstalled.dat o in C:\ProgramData\Epic\UnrealEngineLauncher
Qui troverai i percorsi di installazione dei giochi di Epic Games. 
Puoi modificarli manualmente se necessario.

Project Description

One night in May, while tidying up my system, I realized something unforgivable:
Epic Games doesn’t allow (like Steam does) to move the installation folder from one drive to another.
Basically, if your drive is a little full, you have to uninstall and reinstall everything. And the message you get is a nice “You should’ve thought of that earlier.”
Despite my frustration, I decided not to panic. Instead of doing CTRL+C CTRL+D like any normal person would do, I thought: “Alright, I’ll do it myself!” And that’s how this program was born.

The script will ask you for the necessary information (game name, current installation path, destination folder) and handle the rest: copy or move the files without driving you crazy.
You don’t need to restart Epic Games Launcher for it to recognize the moved files, you just have to select the new destination during installation in the launcher.

ATTENTION/INSTRUCTIONS:

Close Epic Games Launcher before starting the program, to avoid conflicts with files in use.

Run the program as Administrator. After the transfer, Epic Games Launcher will automatically open.

Enter the required data accurately.

Grab a coffee (or two) while the program works. (Essential).

After the transfer, reinstall the game, and when Epic asks you, select a DIFFERENT folder than the one you had selected in my program.

Press “Install,” and Epic Games Launcher will scan for the files you moved. (Spoiler: It will find them).

Bonus: Watch the download bar fly like a rocket!

Play!

Note: If you’re moving heavy games like HITMAN III, the process might take more than one coffee.

In case of problems:
Go to C:\ProgramData\Epic\UnrealEngineLauncher and open the LauncherInstalled.dat file or check in C:\ProgramData\Epic\UnrealEngineLauncher.
Here you will find the installation paths of Epic Games games.
You can manually modify them if necessary.
